# Assets da landing PRO

- `img/`: fotografias da [landing original](https://proprevencaoeperformance.digital/), convertidas para WebP sem ampliar os originais. O maior lado tem no máximo 1080 pixels. `sources.json` registra a origem, as dimensões e o tamanho de cada fotografia. A capa tem uma variante de 640 px para telas menores.
- `fonts/`: Manrope (corpo) e Saira Condensed (títulos), servidas localmente em WOFF2. O subconjunto Latin inclui os caracteres do português. As licenças SIL Open Font License acompanham os arquivos.
- `js/vendor/`: GSAP 3.13.0, com o cabeçalho de licença original. Somente o core é necessário para as animações desta página.

Os retratos ilustrativos de depoimentos da página anterior não foram reutilizados. Os textos dos depoimentos e as fotografias de atletas e mentores foram preservados a partir da fonte fornecida.
